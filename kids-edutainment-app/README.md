# Ocean and Origins Learning Lab

Educational infotainment web app prototype for kids, focused on:

- Sensory perception in animals
- Nature vs nurture learning
- Aquatic animal adaptations and conservation actions
- Ancient and original histories, cultures, and traditions

## Run locally

Open `/Users/ophelia/Desktop/latest resume/kids-edutainment-app/index.html` in a browser.

## Notes

- Built with plain HTML, CSS, and JavaScript.
- Designed to be keyboard accessible and mobile responsive.
- Includes reduced-motion support.
